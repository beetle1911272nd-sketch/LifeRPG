# 3D Asset Sources

Only the small subset used by the game is included; the full packs are not bundled.

## Kenney Fantasy Town Kit 2.0

- Source: https://kenney.nl/assets/fantasy-town-kit
- License: CC0 1.0 (public domain)
- Included: `assets/models/kenney_fantasy_town/`
- Used for the merchant's stalls, stool, and lantern.
- The pack's `License.txt` is included with the models.

## Gobkit Free 3D Assets

- Source and license: https://github.com/Ariescar/gobkit-free-assets
- Model manifest: https://gobkit.com/api/free
- License: CC0 1.0 (public domain), as stated in the source repository and model manifest.
- Included: `assets/models/gobkit/gobkit-bat.glb` and `gobkit-boar.glb`.
- `LICENSE` is included with the models.

The imported enemy models use their bundled idle, walk, and attack animations.
