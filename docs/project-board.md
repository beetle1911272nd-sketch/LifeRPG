# LifeRPG Project Board

## 状態の定義

- Backlog: 話し合い中、まだ着手していない
- Ready: 対応可能で、開始条件が揃っている
- In Progress: 実装または調査中
- Review: 実装完了、レビュー待ち
- Done: 完了済み

## Issue の基本要件

各 Issue には次の項目を含めることを推奨します。

- 目的と背景
- 対象範囲
- 完了条件
- 関連する他の Issue/PR
- 担当者

## 運用メモ

- 仕様が曖昧な項目は議論を Issue に残す
- 実装時の判断は完了条件に紐づけて記録する
- すべての変更は、関連する Issue と PR で追跡できる状態を保つ
