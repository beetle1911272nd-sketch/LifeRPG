# LifeRPG

LifeRPG は、共有で進めるプロジェクトの計画・実装・レビューをまとめるためのリポジトリです。

このリポジトリは、プロダクトの仕様や技術スタックを一気に固定するのではなく、まずは共有の前提と運用を整えるための基盤として作成しています。

## 目的

- 役割と責務を明確にして、開発を進めやすくする
- タスク、進捗、レビューの流れを可視化する
- 仕様が固まる前の検討や方針共有を記録する
- GitHub 上で協業しやすい状態を作る

## 現在の方針

- まだ実装技術や機能範囲は未確定
- まずは文書と運用の整備を優先
- Issue と GitHub Projects を中心にタスクを管理
- 設計や機能が固まった段階で技術選定と実装を進める

## リポジトリの使い方

- `README.md`: 目的・方針・運用の概要
- `CONTRIBUTING.md`: 参加方法と作業フロー
- `docs/`: 詳細な設計や運用メモ
- `.github/ISSUE_TEMPLATE/`: Issue のテンプレート

## 推奨フロー

1. Issue を作成して背景と完了条件を明確にする
2. Backlog / Ready / In Progress / Review / Done の中で状態を管理する
3. 実装・レビュー・マージ後に完了として扱う
4. 仕様が変わった場合は Issue を更新して履歴を残す

## 進行中の整理テーマ

- 目的と対象ユーザーの明確化
- 実装技術の選定
- GitHub Projects の運用ルール確定
- 初期の MVP の定義

このリポジトリは、LifeRPG の共通基盤として使い、将来の機能開発をスムーズに進めるための土台です。
